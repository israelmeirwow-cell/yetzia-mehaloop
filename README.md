# יציאה מהלופ, גרסת Vallora

דף הנחיתה של "יציאה מהלופ" על השלד של התבנית Vallora Estate (React 19, Vite, Tailwind 4, Motion).
עברית מלאה מימין לשמאל, בלי תמונות (רק צבע, טיפוגרפיה וקו הלופ), עם פריסה נפרדת לטלפון.
הטקסטים פונים לגברים ולנשים כאחד: מילים שנכתבות אותו דבר לשני המינים (לך, שלך, אותך), "נבדוק/נתחיל" בגוף ראשון רבים, ו"משאירים פרטים" בלשון רבים. המלוות נשארות בלשון נקבה כי זה הצוות.

## הרצה
```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בונה ל-dist/, את התיקייה הזו מעלים לאחסון
```

## ⚠️ להשלים לפני העלייה לאוויר
- **המלוות:** רז בזק ולבב מלכה, עם תמונות ותחומים, ב-`src/components/Team.tsx` (המערך `mentors`). התמונות ב-`public/images/`.
- **אינסטגרם:** `CONFIG.instagramUrl` ב-`src/lib/loop.ts` (כרגע @raz_bezek_).
- **ווטסאפ:** `CONFIG.whatsappNumber` באותו קובץ (כרגע 972555530881, כמו באתר הקיים).
- ההתכתבות בטלפון בסקשן "משימה אחת ביום" מסומנת כדוגמה.

## מבנה העמוד
Header · Hero (קו הלופ נכתב) · Story (פתקים, המילה "קדימה!" מתעקלת בגלילה) · Lens (כל הרעיונות → זום לתוך הקשת) ·
Stages (חפיסת 4 השלבים) · Marquee · Daily (צ׳אט + 4 עובדות) · Focus · Team · Tools (פריזמה CBT/NLP/SMART) ·
Fit (קורס מול ליווי, למי זה מתאים) · Faq · Contact (טופס שפותח ווטסאפ) · Footer.

מתחת ל-1024 פיקסלים כל סקשן עובר לפריסת טלפון משלו (`useIsMobile`). בגלריה יש לוח נפרד לטלפון.
